### Final Round Info

1. AI Coding
   - Code signal
   - Product Thinking
   - Simplified code of Headway
   - Coding Assistant built in with Code Signal - claude, codex etc
   - you want to use ai tooling like you do everyday
   - itll be a fullstack application
   - use interviewer as a resource and ask questions about the requirements and the product
   - evaluated not exactly on prompting but on ai usage and the output
2. WHO Interview - Behavioral Interview
   - Mostly conversational
   - Use the STAR method - Situation, Task, Action, Result - its a structured method to answer behavioral interview questions
     - Situation (20%): Set the context. Describe the background of a specific event or challenge you faced at a previous job, on an academic project, or during volunteer work. Keep this brief and only provide essential details.
     - Task (10%): Explain your responsibility or the goal you needed to achieve in that situation. What exactly was your role in solving the problem?
     - Action (60%): Describe the steps you personally took to resolve the issue. This is the most important part of your answer. Focus on what you did rather than what your team or manager did.
     - Result (10%): Share the positive outcomes of your actions. Whenever possible, use quantifiable metrics (e.g., "increased sales by 15%") or mention what you learned from the experience.
   - Deep dive into my previous projects - The why, requirements, tradeoffs, and impact (important)
   - Then there will be a bunch of **tell me about a time** kind of questions
   - AI usage questions- how do i use AI in my day to day and where has it been the most helpful etc
3. System Design
   - Design a real world application
   - Whiteboarding via excalidraw from codesignal
   - Looking for a practical solution, avoid overcomplicating or over engineering - they are not looking for scale in this
   - communicate plan before hand
   - make it collaborative like a real design meeting where you are the driver
   - Explain reasoning for design choices, tradeoffs and impact on user experience
4. Coding Project
   - Code Signal
   - Familiarize yourself with Fast API (VVVV important)
   - It will give a starting template on code signal and we have to complete the project (choose python - fast api, JS and TS are other choices)
   - Ask clarifying questions
   - focus on implementation rather then theory
   - its for 1 hour but will mostly only get 45 minutes for actual coding as the rest will take some time during explanation etc
   - discuss pros and cons
   - code quality is important - if youre making compromises let them know
   - evaluated on coding skills

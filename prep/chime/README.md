# Chime - Bank

## Interview Process

1. Technical Interview - Code Signal (DS and Algo)
2. Virtual Onsite (4 interviews)
   - Coding
   - System Design
   - Collaboration Interview - Design
   - Hiring Manager Interview

### Virtual Onsite notes

1. Alex Chen - Coding Leetcode style question - CodeSignal
2. Leon - Distributed System Design White boarding session - via Miro on Code Signal - not API design - proper system design - design a feature for the chime app
   - Discuss tradeoffs while going through design
   - when you select technology - explain pros and cons and why choose specific technology (like sql vs nosql)
   - make sure youre mindful that everything on the whiteboard is correct
3. Stephen - hiring manager for lending team interview - more behavioral focused
   - lens on how he can expect you to perform on the team
   - when you have competing priorities
   - any situation where you had to have difficult conversation - with manager, peer or junior engineer
   - discussions about feedback - giving feedback to manager or receiving feedback from manager - not judging the reason for feedback
   - they just want to know how you navigated those situations
   - how you have leveled up in your career - learning new concepts, taking new initiatives etc
   - let them know why youre interested in chime (v important)
4. Shubhi - behavioral interview - Product Manager
   - with a lens of someone who will be working with you on a project
   - more product focused
   - they are not technical individual
   - how to navigate differing opinions
   - disagreements youve had on type of work, technology etc and how i navigated them
   - let them know why youre interested in chime (v important)
5. Recruiter will join back to answer any lingering questions - timeline for results - 24 - 48 hours
